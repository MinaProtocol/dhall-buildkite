MinaProtocol Dhall Buildkite Bindings

λ Dhall Mina Protocol

This is a base package for MinaProtocol Dhall Buildkite bindings which helps further more specific development for CI of other projects.

📦 How to Use

Each version can be imported into your Dhall project using the following pattern:

https://s3.us-west-2.amazonaws.com/dhall.packages.minaprotocol.com/buildkite/releases/{version}/package.dhall sha256:{sha256}
{version} - Replace with the specific release version (e.g., "1.0.0")
{sha256} - Replace with the SHA256 hash for integrity verification
